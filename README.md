# Mobile Robot Competition

This repository documents a robotics competition project focused on designing and building two mobile robots: one autonomous robot and one manual-controlled robot. The project combines mechanical design, electronics, control programming, testing, and competition documentation into a single development workspace.

The goal is to create competitive robots that can perform assigned field tasks, optimize robot design for reliability, and validate control strategies through repeated testing and iteration.

## Project Overview

The project covers the full engineering cycle for a mobile robot system:

- Mechanical design and CAD modeling
- 3D-printed parts and custom structural components
- Robot assembly and integration
- Sensor, motor, and actuator testing
- Embedded control development and robot programming
- Competition preparation and reporting

The work is divided between:

- Autonomous robot development for self-controlled operation
- Manual robot development for driver-controlled competition tasks
- Testing and tuning for motion, sensing, and field performance

## Repository Structure

- `3D_Printing_Parts_CAD_files/` - CAD files for custom 3D-printed robot parts
- `codes/` - Programming files, testing scripts, and robot control experiments
- `Field_materials_CAD_files/` - Competition field elements and objective models
- `Material_Parts_CAD_files/` - Mechanical and electronic component references
- `Reports/` - Competition-related reports and project documentation
- `Robot_design_CAD_files/` - Full robot assembly and design revisions
- `SuperCool video.mp4` - project video documentation

## Code and Testing

The `codes/` folder contains a mix of control programs and experimental testing work, including:

- Manual control code for robot operation
- Sensor testing folders such as gyro and motor calibration
- Servo and DC motor testing programs
- Development files for iterative competition tuning

This folder reflects the practical process of testing hardware and refining software before final deployment.

## Mechanical Design

The project includes a substantial amount of CAD work for both robot structure and competition field components. These files support:

- Robot frame and mechanism development
- Custom grip, launcher, intake, and support systems
- Part iteration and version tracking
- Full assembly visualization before fabrication

The robot design files show a clear progression from concept to final assembly, with multiple revisions and versions stored in the project.

## Competition Focus

This project is intended to prepare robots for a mobile robotics competition where performance is judged through task completion, reliability, and controlled movement. The system design emphasizes:

- Stability and balance
- Efficient movement and turning
- Sensor-informed control and calibration
- Reusable, modular hardware design
- Continuous refinement based on testing results

## Notes

This GitHub repository is created to organize and share the project work, including design files, software experiments, reports, and competition documentation.

It serves as a record of the team's engineering process and can be used as a reference for future robotics development or similar competition projects.
